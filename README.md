# Zotanovart Studios

A six-page static website starter for Zotanovart Studios, with a warm Mediterranean-inspired palette, arched artwork placeholders, and a subtle donut emblem.

## Pages
- `index.html` — Home
- `about.html` — About the Artist
- `shop.html` — Shop preview
- `portfolio.html` — Portfolio
- `events.html` — Upcoming Events
- `contact.html` — Contact

## Publish
This is plain HTML and CSS. No build command or framework is required. For Cloudflare Pages, use the repository root as the build output directory and leave the build command blank.

## Before going live
Replace the photo placeholders with artwork and studio photos; add real product details and checkout links; connect the contact form to a form service; add studio email/social links; and add confirmed event details. The current shop and contact form are previews and do not process purchases or send messages yet.
